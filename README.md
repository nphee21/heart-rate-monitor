# Heart Rate Monitor (ESP32 + ILI9341 TFT)

An ESP32-based heart rate monitor. An analog pulse sensor measures the pulse waveform from the fingertip. The firmware detects each beat, calculates heart rate in beats per minute (BPM), and shows the live waveform and BPM value on a 320x240 ILI9341 TFT screen. A buzzer and an LED pulse on every detected beat.

Team project for the course [add course name, e.g. "Hệ thống nhúng"] at Ho Chi Minh City University of Technology (HCMUT).


## Features

- Real-time pulse waveform chart (LVGL) and BPM display
- Finger detection and 10-second auto-calibration of the beat threshold
- BPM from inter-beat intervals, averaged over the last 8 valid beats
- Buzzer and LED feedback on every beat
- Periodic BPM log over the serial port

## Hardware

| Part | Connection |
|---|---|
| ESP32 dev board | target `esp32` |
| Analog pulse sensor | OUT -> GPIO34 (ADC1_CH6) |
| ILI9341 TFT (320x240, SPI) | MOSI 23, MISO 19, CLK 18, CS 15, DC 2, RST 4 |
| Buzzer | GPIO26 |
| LED (with resistor) | GPIO25 |

Pin numbers are defined in `main/main.c` and `components/ili9341_lcd/ili9341_lcd.c`.

## Software

## How it works

1. **Sampling**: the ADC (12-bit, 11 dB attenuation) is read every 20 ms (about 50 Hz) and scaled to 10 bits.
2. **Filtering**: a 5-point moving average smooths the signal.
3. **Finger detection**: calibration starts after the signal stays above a threshold for 800 ms.
4. **Calibration (10 s)**: highest and lowest signal values are recorded. The beat threshold is the midpoint between them, and one sixth of the range is used as a tolerance to clamp the displayed waveform.
5. **Beat detection**: a beat is counted when the filtered signal crosses the threshold upward; a state flag prevents counting the same beat twice.
6. **BPM calculation**: the interval between two beats gives an instantaneous BPM (`60000 / interval_ms`). Intervals outside 300-2000 ms and values outside 50-130 BPM are rejected, and the last 8 valid values are averaged.
7. **Output**: LVGL chart (83 points), BPM label, buzzer and LED for 100 ms per beat, and a log line every 10 s.

## Build and flash

```bash
idf.py set-target esp32
idf.py build
idf.py -p <PORT> flash monitor
```

Managed components (LVGL, ILI9341 driver) are downloaded automatically on the first build.

## Usage

1. Power the board. The screen shows "Touch the sensor to start".
2. Rest a finger on the pulse sensor and hold still.
3. After a short countdown and a 10-second calibration, the waveform and BPM appear.

## Possible improvements

- Use the newer ESP-IDF ADC API (`esp_adc/adc_oneshot.h`); `driver/adc.h` is deprecated in ESP-IDF 5.x
- Widen or configure the accepted BPM range (currently 50-130 BPM)
- Re-calibrate automatically when the signal amplitude changes
